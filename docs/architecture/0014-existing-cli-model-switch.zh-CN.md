# 已有 CLI 会话内切换模型

2026-10-30，用户明确要求打通 Copilot CLI 和 Antigravity 已有会话中的模型切换，只展示同会话可切模型，正确保留推理与工具审批设置；当前客户端不重启。

## 职责与接口

- 两个适配器通过 `supportsModelSwitch` 公布可恢复同一 CLI session 并应用新模型的能力；其他适配器默认不开放。模型目录将其转为 `canSwitchModel`。没有新增后端服务或第二份会话存储。
- `GatewayProtocol` 独占模型和策略的持久状态。`thread/settings/update` 新增 model 字段，模型必须属于原 engineId，适配器类型必须与已存会话相同。目录异步读取完成后，在同一同步段读取最新会话、验证全部参数、原子写入；错误不能留下部分修改。
- `createCliSelectorServices` 将页面限定模型 ID 转回网关 ID，发送单独的设置请求。选择模型不创建线程，不提交 turn，不修改原生配置。通用 DIY 组件只消费目录、设置服务和会话控制器，不导入 CLI SDK。
- 已有 CLI 会话的菜单仅显示当前 engineId 下具备切换能力的模型及当前值，不显示 Codex、其他 CLI 或另一 provider。目录不可用时保留当前值，不猜测可用型号。新建草稿仍可选择各已配置引擎；原生会话继续使用原生控件。

## 设置保持与生效时点

切换保存后对下一条消息生效。已有推理强度仍在目标模型目录中时原样保留；否则使用目标模型公布的默认值，页面明确显示调整原因。用户同时显式提交不支持的强度时拒绝整次设置，不擅自替换。审批策略独立保留，不因换模型而重置；不兼容的审批值也不能静默降低。

没有手动推理档位的模型（例如 CLI Auto）显示“CLI 默认”，不将内部占位值 none 误称为真实“无推理”。从这类模型切回可调模型时采用目标默认值，只有用户可选的明确推理值才按兼容性保留。

切换不改变工作目录、项目、历史、engineId 或 CLI session ID。正在执行的轮次继续使用入场时选定的模型与推理；执行快照保存会保留最新 model 和设置，不能把下一轮意图覆盖回旧值。审批策略沿用既有实时读取规则。

保存尚未完成时，会话控制器拒绝新发送并给出明确错误，不把消息送往旧模型，也不自动重试。保存后发送须匹配当前已保存模型；其他窗口的过期参数会被拒绝，不能通过一次旧的 turn/start 将模型切回。模型变更的所有权落在设置接口。

## 验证与加载状态

源码构建和回归记录见同目录 evidence。确定性检查覆盖同引擎切换、兼容/不兼容推理、审批保留、运行中切换、并发保存边界、冷恢复、非法请求原子拒绝、保存期间拒绝发送，以及原生权限和路由隔离。独立浏览器覆盖菜单筛选、实际 DOM 交互、保存失败恢复、推理调整提示和重新挂载。

真实 CLI 探针为 `tools/probe-cli-model-switch.mjs`：只读生产连接配置定位已安装 CLI，在临时账号配置、工作目录和网关中创建独立测试会话；模型必须来自实际目录。每个引擎使用两轮限定文本，第一轮提供随机 nonce，换模型并重建临时网关后要求第二模型在没有新提示中 nonce 的情况下复述，核对同一 CLI session ID、模型、推理及审批。Copilot 额外反查真实 `session.rpc.model.getCurrent`；Antigravity 使用官方 session config 的模型/推理确认。测试不连接生产 Desktop / gateway，不发送用户已有会话消息，工具策略设为 deny。临时凭据和工作数据在 finally 删除，仅保留非敏感报告。

当前客户端、生产网关和页面助手均保持原生命周期，没有为了验收重启或热替换。此功能已编译到本机源码产物，需后续协调加载新版网关与 UI 后再做原窗口验收；不能将临时 CLI 或浏览器探针当作当前生产窗口已生效。

没有修改 VERSION、native core、官方客户端文件、全局配置或已有真实会话策略，没有运行跨平台发行构建，未提交、推送或发布。

## 本机验收结果

- 严格 TypeScript 构建：30 个源码模块、60 个输出。87 项定向回归在 `--test-concurrency=3` 下全通过，无取消或跳过；覆盖两个固定 Mac 启动合同和原生 provider 隔离。此前一轮启动测试超时，串行复核也出现超时，未将其解释为确定的业务故障或通过延长测试时限隐藏；随后完整受控并发运行通过，未放宽断言。
- 独立浏览器：29 项检查全通过，包括同引擎菜单、兼容强度保留、目标默认值提示、CLI 默认语义、切换失败恢复、冷挂载和原生权限保留。导航期间组件会卸载再挂载，fixture 等待条件以实际出现为准。
- 真实 Copilot CLI：GPT-6.1 Sol → GPT-6 Luna，运行时分别反查到两个具体型号及 high；独立会话的 session ID、deny 审批、随机 nonce 和两轮历史在重建临时网关后保留。
- 真实 Antigravity：Gemini 3.8 Flash → Gemini 4 Argon，使用官方配置确认模型与 high，重建临时网关后同 session、deny、nonce 和两轮历史保持。该次联合验收四轮成功，原生 Codex 推理调用为零。
- 真实探针首次尝试的 Copilot Sol → Auto 已成功，但 Antigravity 出现一次 RPC 超时，未自动重放不确定轮次；已清理该临时实例。增加诊断后使用新的独立会话与具体型号重新验收，两条路线均通过。失败记录和成功记录分开保留。
