# ADR 0023：不中断工作客户端的临时宿主验收

日期：2026-11-02（Asia/Shanghai）。用户同意使用临时验收实例，保持现有工作客户端和活跃会话运行。本入口只用于开发验证，日常产品入口仍是原 MyCodex 与原官方客户端/profile。

## 1. 实现与归属

新增严格 TypeScript 模块 `bridge/desktop-acceptance.mts`，复用现有签名校验、精确版本/ASAR/CLI 合同、路由器、网关、Spine 和页面助手。旧 R0 探针保留，没有运行其中的 CDP 点击、DOM 读取或截图代码。

- `prepare <official.app> <radar.schema.json>`：在新建、私有且带归属标记的短临时目录复制已签名客户端，再核对完整文件摘要；不注册新日常入口，不更改官方包。雷达 schema 显式传入并复制到测试目录。
- `run <owned-root> [lifetime-ms]`：启动专属 socket/凭据/网关，以及复制后的官方客户端和现有产品页面助手。HOME、CODEX_HOME、Desktop user-data、缓存、临时目录和工作目录均独立，不复制原聊天库、账号、配置或凭据。默认 30 分钟，最多 1 小时；关闭测试窗口后监督进程结束测试网关和助手。
- `cleanup <owned-root>`：核对归属和进程寿命后删除本入口的临时文件；拒绝未标记目录、逃逸链接、错误回执或仍运行的实例。测试进程按独立进程组/明确快照路径和进程寿命回收，不按应用名或 bundle ID 广泛结束进程。

合成原生传输复用已有 `tests/fixtures/desktop-app-server-probe.mjs`，由 `routed-stdio.mts` 与测试网关组成真实 IPC 链。它报告未登录状态，没有原生模型进程。测试引擎目录只有 `acceptance/fixture`；仅接受 `MYCODEX_ACCEPTANCE_PING` 哨兵，其他工作请求明确失败，不执行外部工具或调用模型。预置 `MYCODEX-ACCEPTANCE-IMAGE` 聊天通过正式网关协议写入一轮文本与 480×240 PNG，图片经过正式媒体存储与官方 `imageGeneration` 投影。雷达和日报使用合成报告及测试聊天，没有连接私人知识库。

这个实例运行的是官方 renderer 和本次产品接缝，因此比独立 Chrome fixture 多验证了真实宿主集成。合成后端并不证明真实账号、模型额度、云端功能和所有原 profile 共存场景。

## 2. 隔离边界与失败证据

曾尝试在 GUI 外叠加 `sandbox-exec` 来限制文件写入和外网。真实启动日志证明 Chromium 会忽略 TMPDIR，在 macOS 用户系统临时目录创建单实例 socket；放行该临时目录后，又出现 Chromium 子进程无法初始化自身沙箱、GPU/网络服务退出。该方案没有继续用于 GUI。

最终 GUI 保留客户端自带沙箱，使用独立进程、profile 和合成后端；没有添加 `--no-sandbox` 或降低 renderer 沙箱。GUI 不是虚拟机，也没有系统级断网承诺；官方客户端可能产生自己的网络/系统临时活动。原配置及进程寿命通过前后对照核验。

`acceptanceSandbox()` 仅用于后台协议探针，实际验证私有目录写入、目录外写入拒绝、外网拒绝，以及本轮 Unix socket/本机 IPC 可用，不套在 Electron 或页面助手外层。过渡期间为 GUI 增加的系统临时目录例外已移除。

另外补上两处启动时序合同：等待启动器 exec 成预期二进制，再等待该寿命真正拥有独立 loopback 端口；尚未监听与身份/端口不匹配均不允许附着。回归覆盖延迟 exec、延迟监听及错误寿命拒绝。

## 3. 本轮真实验收

当前安装为 `26.1027.51404`，使用现有精确合同，没有放宽文件摘要校验。临时客户端 PID 4262，助手 PID 4297；产品助手先报告 ready，再由用户在临时窗口反馈：**“图片、雷达/日报、Escape 都正常”**。

该反馈验收了：

1. 预置聊天的图片在真实原生正文显示。
2. 右上角 MyCodex 抽屉中的雷达/日报可展开。
3. Escape 关闭抽屉正常。

反馈不扩展为原窗口全部功能通过，也不扩展为点赞、入库、真实数据刷新或真实模型调用的人工验收。这些交互已有隔离浏览器/协议回归；真实数据源配置仍需单独接入和验证。

用户反馈后只结束测试监督进程及其私有子进程。两个临时客户端/工作目录已清理，未保留新的日常客户端或 profile。本次测试前后，工作客户端 PID 68483、网关 PID 68440、助手 PID 68542 的寿命保持；8 个基线文件哈希不变。VERSION、native patch chain、共享 DEVELOPMENT 文档保持，无提交、推送或发布。

## 4. 门禁

新增 6 项定向检查，纳入 `test:diy`。最终 typecheck、build、238/238 完整测试、191 个 ESM 模块 / 459 条相对导入检查通过；本轮明确文件的源码审计和生成产物新鲜度另列于证据。

第一次整套运行有共享工作区新增状态 CLI 测试的默认引擎配置失败（235/236）。本次未修改该测试；共享现场随后已有有效默认引擎配置，最终整套通过。初期验收入口的类型错误、测试请求视图/排序错误、启动等待和 GUI 外层沙箱失败没有改写成成功；相应日志保存在任务临时证据路径。
