# 模型来源、密钥管理与会话引擎边界

模型来源管理复用本机 API bridge。`ccodex sources` 打开该实例的 `/sources` 页面；新聊天优先来源、模型名称和最近一次请求来源分别显示。来源可命名，同一服务的多套 key 也可保存为独立来源。普通读取只返回脱敏 key，点击查看才显示完整 key；30 秒后、离开页面或切换来源时隐藏。不向浏览器存储、聊天、源码或日志写入 key。

来源注册表位于 bridge profile 的 `model-sources/sources.json`，在 macOS 上目录为 `0700`、文件为 `0600`，这是本机私有文件存储，不宣称系统钥匙串或静态加密。管理页面只服务于受校验的 loopback Host；写入、目录读取和 key 查看需要页面专用能力和匹配 Origin，没有跨站 CORS 或 iframe 入口。更新采用版本校验，拒绝链接文件，服务地址及协议绑定来源 ID；修改服务地址须新增来源，更新 key 则属于同一服务的显式轮换。

模型来自用户指定服务的 `/models`。标准接口未声明的上下文、视觉和推理选项不从模型名字推断；当前使用保守的本地上下文预算，不冒称服务商保证。图片生成专用模型不放入聊天目录。目录可见不证明该账户能够调用所有模型。Responses 和 Chat Completions 分别复用已有桥接路径，凭据只发给该来源；拒绝重定向，认证失败不尝试 Copilot 或另一来源的 key。源绑定编码在模型标识中，修改新聊天偏好不会改变已有聊天的请求去向。

执行引擎在创建聊天前选择；聊天创建后固定引擎。会更换原生凭据或运行时的模型来源也固定。已有聊天的模型列表只显示同一引擎、同一来源中支持会话内切换的模型，并保留当前模型作为已提交状态。引擎和来源显示为不可修改；更换它们需要新建聊天。

输入区使用单个紧凑入口，设置在弹层中按执行引擎、模型来源、模型分组，点击应用才提交选择；推理和审批只在有对应能力时显示，不显示无意义的“CLI 默认”。同一原生凭据来源中的模型/推理变更复用客户端已有选择动作并核对其确认，保持内部会话。原生默认 Codex 也使用受限列表；它的裸模型标识不转换为 CLI 标识。失败时摘要仍显示已提交的模型，保留草稿，弹层显示失败原因。

原生默认 Codex 的响应速度设置保留：读取客户端对当前账号和模型提供的标准/快速选项，调用其 `onSelectServiceTier` 动作，并等待选择状态确认。加载、拒绝、超时或聊天/模型变化时不重放动作；不写网关偏好，也不把原生快速模式套用到第三方引擎。

后端同步拒绝 `gateway/conversation/switch`、`thread/execution/switch` 和 `gateway/thread/adopt` 的跨运行时接续。原生 router 不再读取历史并把原生聊天 ID 交给网关。普通设置、发送、恢复接口继续核对现有引擎归属；不支持换模型的适配器拒绝模型变更。前端隐藏选项不能替代这些校验。

旧版已经保存的接续记录仍按当前已提交的引擎恢复，不自动迁移、还原或重放历史。旧记录的身份遮蔽、待接续上下文及清理引用保持可读；禁止创建新的跨引擎接续，不等于删除旧聊天的数据或恢复能力。

删除旧接续聊天时，网关保留各次执行的最小清理引用，并清理支持删除的 CLI 档案；缺失原始适配器或原生档案清理连接时保持待清理，不冒称原始档案已删除。独立分支不继承原聊天的清理所有权。标准 ChatGPT 登录的原生模型目录不被改写；新聊天可选择本实例已经配置的引擎与来源。

本机验证使用隔离 profile，覆盖创建时选择引擎、已有聊天的引擎/来源锁定、同引擎换模型、原生模型确认、跨引擎请求无副作用拒绝，以及旧接续记录的恢复与清理。浏览器验证草稿保留及原生默认 Codex、Copilot/API 两类受限列表。正在运行的 stdio 前端和 UI helper 不会因源码变化自动更换；任务结束后正常重开 MyCodex 才加载新的引擎边界。
