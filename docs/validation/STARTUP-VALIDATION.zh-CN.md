# Ccodex 启动升级验收

本文件是此前启动优化的历史基线，并非本轮 UI 修复的重新计时结果。
当前安装包摘要及交互验收见 [本轮界面修复验收](UI-VALIDATION.zh-CN.md)。

开发者继续使用 **ccodex-dev / Ccodex Dev Desktop**；同事安装独立 **ccodex / Ccodex Desktop**。公开版本仍为 1.2.35，本次覆盖现有 Release 的同名文件。

## 已完成

安装阶段完成重资源校验、固定文档运行时和原生状态准备。日常启动复用与安装槽、资源完整身份绑定的校验缓存；资源变更会重新哈希。Desktop 通过真实后端及进程归属验证，不以出现窗口作为成功依据。

开发版 `ccodex-dev source` 定位维护源码，`ccodex-dev sync` 同步启动器、桥接、工具与辅助模块，不替换原生核心，不关闭当前任务。新 CLI 使用新代码；已打开的 Desktop 正常退出后重开使用新版界面。

两种架构的最终 EXE 均实际安装、退出码为 0，逐文件压缩资源核验通过，每种架构 220 项回归通过。实际 GUI 无可见终端，中文和增强控件正常，CLI 正常退出。启动测试使用预置模拟账户/模型目录，不含真实首次登录时间或付费请求。

X64 使用 Windows ARM64 的 x64 仿真，未在物理 x64 主机实测。程序首次授权、引导、工作目录信任和终端安全扫描可能额外耗时；不保证所有电脑有相同延迟。

## 目录

Release 默认程序与数据位于当前用户 LocalAppData 的 CCodexRelease，CLI 保持调用目录，快捷方式默认从“文档/Ccodex Workspace”打开。开发版保留自己的 CodexCopilot 程序及 .codex-copilot profile；默认工作目录为用户主目录/Ccodex Workspace。Desktop 使用所选项目的任务目录。

独立的是软件和本地数据，不是虚拟机。共享项目及项目配置、系统代理/防火墙、云端账户权益仍可能影响两边。详见各架构验收报告和 DEVELOPER-AND-RELEASE.zh-CN.md。
